# SONORE-REQ-006 — AI-ассистент для школы

**Проект:** Sonore AI Transformation
**Статус:** Draft
**Приоритет:** Low

## Описание

AI-ассистент для автоматизации рутинных задач школы.

## Функциональные требования

- FR-6.1 AI-чат для ответов на частые вопросы (цены, расписание, направления)
- FR-6.2 AI-генерация описаний услуг и контента для сайта
- FR-6.3 AI-анализ обратной связи учеников
- FR-6.4 AI-рекомендации по маркетингу
- FR-6.5 AI-подбор репертуара под уровень ученика
- FR-6.6 Голосовой ассистент (Telegram-бот)

## Нефункциональные требования

- NFR-6.1 Интеграция с LLM (через API)
- NFR-6.2 Безопасность промптов
