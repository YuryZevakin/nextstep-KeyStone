# SONORE-REQ-007 — Соответствие GDPR (RODO)

**Проект:** Sonore AI Transformation
**Статус:** Draft
**Приоритет:** High

## Описание

Сайт и система должны соответствовать требованиям GDPR (RODO) — Общего регламента по защите данных Евросоюза. Школа работает в Польше, поэтому соблюдение RODO обязательно.

## Функциональные требования

### Политика конфиденциальности
- FR-7.1 Страница с политикой конфиденциальности (Polityka prywatności)
- FR-7.2 Информация о том, какие данные собираются (имя, email, телефон)
- FR-7.3 Цель сбора данных (запись на занятия, коммуникация)
- FR-7.4 Срок хранения данных
- FR-7.5 Права субъекта данных (доступ, исправление, удаление, перенос)

### Cookie-уведомление
- FR-7.6 Баннер/уведомление об использовании cookies при первом посещении
- FR-7.7 Возможность согласиться или отклонить необязательные cookies
- FR-7.8 Ссылка на Politykę prywatności в баннере

### Формы сбора данных
- FR-7.9 Чекбокс согласия на обработку персональных данных в форме записи
- FR-7.10 Ссылка на Politykę prywatności рядом с чекбоксом
- FR-7.11 Явное указание цели сбора данных в форме
- FR-7.12 Невозможность отправки формы без согласия

### Защита данных
- FR-7.13 Шифрование передачи данных (HTTPS)
- FR-7.14 Безопасное хранение паролей (хеширование)
- FR-7.15 Ограничение доступа к данным только уполномоченным лицам
- FR-7.16 Логирование действий с персональными данными

### Права субъектов
- FR-7.17 Механизм запроса на удаление данных ("право быть забытым")
- FR-7.18 Механизм запроса на экспорт данных
- FR-7.19 Возможность исправления неверных данных
- FR-7.20 Контакт для запросов RODO (email)

### Контактная информация
- FR-7.21 Указание Inspektora Ochrony Danych (IOD) или контакта по RODO
- FR-7.22 Email для RODO-запросов (например, rodo@sonoremusic.pl)
- FR-7.23 Информация о праве подачи жалобы в PUODO (Urząd Ochrony Danych Osobowych)

## Нефункциональные требования

- NFR-7.1 Соответствие RODO (польская имплементация GDPR)
- NFR-7.2 Документирование обработки данных (Rejestr czynności przetwarzania)
- NFR-7.3 Уведомление об утечке данных в течение 72 часов
